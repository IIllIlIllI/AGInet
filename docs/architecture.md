# AGInet Architecture

AGInet is an experimental epistemic infrastructure designed to analyze claims, narratives, and information ecosystems.

The system focuses on reasoning about **claims and their relationships**, rather than simply retrieving documents.

---

## Core Flow


INPUT queries • documents • media │ ▼ CLAIM EXTRACTION identify assertions │ ▼ CLAIM GRAPH supports / contradicts relationships │ ▼ SCORING ENGINE trust bands • independence • provenance │ ▼ AGENT COUNCIL multi-perspective reasoning │ ▼ GOVERNANCE resolution • uncertainty • escalation │ ▼ OUTPUT answers • explanations • insight paths

---

## Claim Graph

Claims become nodes in a graph.

Relationships include:

- supports
- contradicts
- elaborates
- speculative

This structure allows the system to reason about **information structure**.

---

## Trust Bands

Instead of simple rankings, results are grouped into trust bands based on:

- corroboration
- independence of sources
- contradiction structure
- provenance strength

---

## Observability

AGInet includes observability systems to detect epistemic drift:

- claim graph topology drift
- contradiction rate
- trust band movement
- mode disagreement
- promotion anomalies
